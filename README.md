Programa de Ingeniería de Software

> ⚠️  realizar la maquetación de una página web haciendo uso de los elementos de HTML y modificando su estilo a través de CSS.

## Cómo ejecutar
1. Descarga este paquete y descomprímelo.
2. Abre `index.html` en tu navegador.

## Estructura
- `index.html`: Maquetación HTML semántica y metadatos (`meta charset`, `viewport`, `description`, `robots`).  
- `styles.css`: **CSS externo**: layout, tipografía, temas claro/oscuro, componentes (botón, card, grid).  
- `script.js`: **JavaScript** para modificar estructura y estilos: menú accesible con ARIA, validación de formulario, inserción dinámica de nodos, cambio de tema.
